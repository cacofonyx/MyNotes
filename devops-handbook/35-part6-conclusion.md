# Part VI — Conclusion

Part VI applied DevOps principles to Information Security — making security everyone's job, every day. Better security means being defensible with data, recovering from security problems before they become catastrophic, and continuously improving security posture.

## Key Resources

- Auditor's Panel, DevOps Enterprise Summit 2019 — how DevOps and audit work together (representatives from all four big auditing firms)
- *Sooner Safer Happier* (Smart et al.) — building intelligent control in regulated industries; patterns and antipatterns from banking
- *Safety Differently* (Sidney Dekker) — turning safety from bureaucratic accountability into ethical responsibility; embracing human factor as solution, not problem

> **[SRE Lens]** Part VI's message for SRE: security and reliability are not competing concerns — they're complementary. The same practices that make systems reliable (automated testing, small deployments, telemetry, peer review) also make them secure. The same cultural practices that improve reliability (blameless postmortems, shared knowledge, continuous improvement) improve security posture. SRE teams that integrate security into their operational practices — security-aware SLOs, security incident postmortems, automated compliance checks in deployment pipelines — are delivering on Part VI's vision.
